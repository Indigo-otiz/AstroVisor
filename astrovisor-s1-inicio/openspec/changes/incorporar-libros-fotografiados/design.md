# Diseño

## Context

El ZIP contiene fotos de portadas y créditos de ejemplares. El catálogo actual exige un enlace HTTPS por libro y la estantería 3D presenta hasta tres recomendaciones.

## Decisions

- Crear un inventario por ejemplar y conservar por separado los tres números de revista. Usar una foto de portada por ficha, corregir su orientación y recortar el fondo si hace falta. Conservar las demás fotos como evidencia de lectura.
- Usar datos legibles en las fotos. Omitir año, edición, signatura o ubicación si no se pueden acreditar. Cuando falte un enlace público verificable, ajustar el contrato y los consumidores para representar su ausencia.
- Registrar por qué cada título se vincula a Orión, Osa Mayor, Escorpio, Can Mayor o Boyero. Los títulos que tratan temas generales, como la Tierra o el Sistema Solar, se presentan como lecturas complementarias. No afirmar que cubren una constelación sin evidencia.
- Reutilizar la validación, almacenamiento y exportación de portadas fotográficas. Incorporar el catálogo por ID para preservar las ediciones previas al actualizar una instalación.
- Mostrar todas las lecturas asociadas en la web. En Homido ofrecer conjuntos pequeños de portadas y navegación por mirada o clic para llegar a todas.

## Distribución inicial

La relación es temática cuando la foto no documenta una mención directa. Las dos publicaciones sobre el Sistema Solar corresponden a ediciones distintas.
