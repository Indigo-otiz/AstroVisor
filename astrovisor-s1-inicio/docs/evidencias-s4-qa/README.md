# Evidencias de QA Físico — Sprint 4 (Karime)

Este directorio almacena las evidencias gráficas, registros técnicos y video de respaldo de la prueba física realizada con smartphone y visor Homido para el Sprint 4 (revisión 3/11 y Expo 5/11).

## Nomenclatura de Archivos de Evidencia

1. **Fotografía / Video de uso físico:**
   - `homido-dispositivo-fisico.jpg` (o `.mp4`): Fotografía o video corto del teléfono colocado dentro del visor Homido real durante la ejecución.
2. **Capturas de pantalla del flujo inmersivo en el móvil:**
   - `01-permisos-sensores-audio.png`: Diálogo de permisos de sensores y botón de audio activo.
   - `02-vista-dividida-estereo.png`: Vista estéreo con las dos mitades alineadas.
   - `03-seleccion-mirada-orion.png`: Aro de permanencia (dwell) progresando sobre Orión.
   - `04-ficha-audio-reproduciendo.png`: Ficha abierta con control de audio activo.
   - `05-estanteria-libros-demo.png`: Estantería 3D mostrando el rótulo `DEMO`.
   - `06-salida-modo-2d.png`: Retorno a la interfaz 2D accesible.
3. **Video de Respaldo para la Expo (5 minutos):**
   - `recorrido-respaldo-expo-5min.mp4` (o enlace local / almacenamiento institucional registrado en este documento si el peso excede los límites de Git).
